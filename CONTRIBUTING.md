# Contributing

Contributions are welcome when they improve accessibility, reproducibility or source accuracy.

- Prefer stable primary sources.
- Separate observed, audited, proposed, inferred and unknown claims.
- State the source date and scope boundary.
- Do not add tactical recommendations, targeting, classified plans or invented probabilities.
- Run `npm run lint` and `npm test` before opening a pull request.

# Publication invariant

The README must keep the production website link prominently visible directly below the project introduction. Before publishing a release, verify that the README link and GitHub repository homepage both resolve to the current production deployment.
